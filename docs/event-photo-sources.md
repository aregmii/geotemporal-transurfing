# Reviewed event photographs

Audited 2026-09-05. 23 new event associations and 38 retained from the earlier demo, all using existing local JPEGs. No new images downloaded.

This manifest is used by the production application. Identity includes the original source slug, date, latitude, and longitude; a shared Wikipedia article is insufficient to assign a photograph.

Photographs are archival media. A photograph can show an event, a later consequence, or related context. The photo date and camera location are kept separately from the event date and globe marker. All local JPEGs were resized and re-encoded by the existing pipeline.
